# What's Built

## ✅ Database Layer
- **8 Tables**: raw_scrapes, properties, price_history, tax_history, property_images, 
  open_houses, leads, scrape_errors
- **Async SQLAlchemy**: All models use async/await with asyncpg
- **Deduplication**: Multi-step logic (platform ID → address+zip → new)
- **Migrations**: Alembic async setup ready for first migration

## ✅ Transport Layer
- **HTTP Client**: httpx wrapper with retry logic (tenacity)
- **Playwright**: Async browser for JS-heavy sites
- **Selenium**: Sync fallback (runs in thread pool)

# How to Use

## Setup
```bash
# Copy .env
cp .env.example .env

# Start Postgres + Redis
docker-compose up -d

# Create venv
python -m venv venv
venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run migrations
alembic upgrade head
```

## Run Scraper (When Implemented)
```bash
# Scrape Zillow for FL
python main.py scrape --source zillow --state FL

# Scrape all sources for CA
python main.py scrape --source all --state CA

# Retry failed URLs
python main.py retry --source zillow --state FL

# Start periodic scheduler
python main.py scheduler
```

# Architecture Decisions

1. **Async Everywhere**: SQLAlchemy async + asyncpg + Playwright + httpx
2. **Sequential Scraping**: No concurrency.gather() to avoid detection
3. **Deduplication**: Multi-step (platform ID → normalized address+zip)
4. **Raw Blob Storage**: Never lose raw JSON response
5. **Platform Separation**: Scrapers and normalizers kept separate
6. **Error Resilience**: Every failure logged to scrape_errors table
7. **Proxies Disabled**: Enable via PROXY_ENABLED=true when needed
8. **Configurable Everything**: All settings in .env
